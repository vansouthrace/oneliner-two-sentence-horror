A two-sentence horror story, written for the [make.fun bounty](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253).

The first sentence is comfort; the second takes it away. The voice is familiar, the listener is not the person it belongs to.

## Entry

> My grandmother's voice still reads me bedtime stories through the old radio. Last night she paused, and said, 'You are not my grandson.'

## Run

```sh
node main.ts
```

Writes the story to `/output/entry.txt`.
